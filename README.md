# c-math-operations

## 📌 Description
A simple C program that calculates the **sum**, **product**, and **average** of two numbers using **functions and pointers**. This project helps beginners understand core C programming concepts.

---

## 🚀 Features
- Calculates the sum of two numbers
- Calculates the product of two numbers
- Calculates the average of two numbers
- Uses pointers to return multiple values from a function

---

## 🛠️ Technologies Used
- Language: C
- Concepts: Functions, Pointers, Arithmetic Operations
